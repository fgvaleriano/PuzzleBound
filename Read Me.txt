Project Title: Puzzle Bound

Developed by: Joshua Chu, Dizahlene Catenza, Lander Valeriano  


───────────────────────────────────────────
1. Project Overview
───────────────────────────────────────────
Puzzle Bound is a 2D platformer game designed to challenge players through unconventional and thought-provoking level mechanics.  
While it initially presents itself as a traditional platformer — where the primary objective is to reach an exit — each level introduces unique and unexpected twists that subvert standard gameplay logic.  
This design approach encourages players to think creatively, reinterpret rules, and solve platforming puzzles that require out-of-the-box strategies.

The game was developed using Java and utilizes pixel-art-based visual and audio assets.

3. To Play
───────────────────────────────────────────

**Instructions to Run the PuzzleBound**


To play Puzzle Bound, please follow these steps:

1. Open your terminal or command prompt and navigate to the root folder of the project.

2. Compile the game files by running the following command: javac src/PuzzleBound.java

3. Once the compilation is complete, run the game using: java src.PuzzleBound

Make sure that the `assets/` folder is located in the root directory, as it is required for loading images, sounds, and other game content.
